## Five Video Scripts

### 1. Python in 10 Minutes
**Hook:** "Want to start coding but Python looks confusing? In the next 10 minutes, you'll write your first useful Python program."

**Script:**
"Welcome to CodeSprint Academy. Python is popular because its syntax is readable and it lets beginners focus on logic. Start with a variable: `name = 'Mimi'`. Print it with `print(name)`. Next, use input: `name = input('What is your name? ')`. Conditions let programs make decisions: `if age >= 18: print('Adult') else: print('Minor')`. Loops repeat work: `for i in range(5): print(i)`. Functions package reusable logic: `def add(a, b): return a + b`. Your practice task is to build a program that asks for a user's name and three marks, calculates the average, and prints pass/fail. Don't just watch—code it yourself."

### 2. Git & GitHub for Beginners
**Hook:** "If you can code but your projects are not organized on GitHub, you're missing an important developer skill."

**Script:**
"Git tracks changes in your project. GitHub hosts repositories online and makes collaboration easier. Create a repository, clone it, edit a file, then run `git add .`, `git commit -m 'Add first version'`, and `git push`. Think of Git as a timeline of your project. A commit is a checkpoint. Branches let you work safely on a feature. Your practice task: create a repository, add a README, make three commits, and push them."

### 3. Build a Job-Ready GitHub Portfolio
**Hook:** "Your GitHub should tell a recruiter what you can build in less than one minute."

**Script:**
"Start with a clear profile README. Pin your strongest projects. Each project needs a useful README: problem, features, technology, setup, screenshots, and what you learned. Avoid repositories containing only class notes. Build three projects at increasing difficulty: a Python utility, a data/dashboard project, and an API-backed application. Commit regularly and write meaningful commit messages. Finish by checking that every pinned project can be run or understood by someone who has never seen it before."

### 4. What Is an API?
**Hook:** "When an app shows weather, payments, maps or AI results, how does it get that data? Often, through an API."

**Script:**
"An API is a defined way for software systems to communicate. Imagine a restaurant: you place an order with the waiter, the kitchen processes it, and the waiter brings the response. In an HTTP API, a client sends a request to an endpoint and receives a response, often JSON. A GET request commonly retrieves data; POST commonly sends new data. In Python, the `requests` library can call an API and `response.json()` can parse JSON. Your practice task is to call a public API, print one useful field, and handle an error response."

### 5. Python Expense Tracker Mini Project
**Hook:** "Let's turn Python basics into something you can actually use: a command-line expense tracker."

**Script:**
"Our app needs three operations: add an expense, list expenses, and calculate the total. Store each expense as a dictionary with amount and category. Put dictionaries into a list. Use a loop to show a menu. When the user chooses Add, collect the amount and category. When they choose List, display each record. For Total, use `sum()` over the amounts. Finally, validate input so a text value cannot crash the program. This project demonstrates variables, lists, dictionaries, functions, loops, conditions, validation, and real-world problem solving. Extend it next by saving data to a CSV or JSON file."
