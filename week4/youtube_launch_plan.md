# YouTube Launch Plan

## Channel
**CodeSprint Academy**

**Tagline:** Learn. Build. Get Job-Ready.

**Niche:** Beginner programming, practical projects, Git/GitHub, APIs, and early-career developer skills.

## Channel setup
- Profile image: `>` / sprint mark using the brand palette from earlier weeks.
- Banner copy: **Learn. Build. Get Job-Ready. | Python • Projects • Developer Skills**
- About section: Beginner-friendly programming lessons with one concrete outcome per video.
- Playlists: Python for Beginners; Git & GitHub; Build Projects; Developer Career Skills.
- Upload defaults: concise value proposition, chapters where useful, resource links, CTA to subscribe and build.

## SEO framework
- Put the main search phrase near the beginning of the title.
- Explain the learner outcome in the first 1–2 description sentences.
- Add chapters and relevant resource links.
- Use a small set of highly relevant keywords/hashtags.
- Keep thumbnails readable at mobile size.

## Publishing cadence
- Monday: Video 1
- Wednesday: Short 1 + Short 2
- Thursday: Video 2
- Friday: Short 3 + Short 4
- Sunday: Video 3 + Short 5
