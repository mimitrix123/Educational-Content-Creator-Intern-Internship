# Week 4 — Five Short-Form Clips

## 1. Python Expense Tracker
**Hook:** “Need a Python project for your GitHub?”
**Core:** Show the list → input → append → sum flow in a fast sequence.
**CTA:** “Build your version and watch the full tutorial.”

## 2. Python Beginner Mistakes
**Hook:** “Stop making these three Python mistakes.”
**Core:** Explain input type conversion, meaningful variable names, and incremental testing.
**CTA:** “Save this before your next Python project.”

## 3. Git vs GitHub
**Hook:** “Git and GitHub are NOT the same thing.”
**Core:** Git manages version history locally; GitHub hosts repositories online for sharing/collaboration.
**CTA:** “Follow for more developer basics.”

## 4. What Is an API?
**Hook:** “How does one app talk to another?”
**Core:** Explain API as the interface that lets software request and receive data/services, with a simple restaurant analogy.
**CTA:** “Watch the full API lesson.”

## 5. GitHub Portfolio Tips
**Hook:** “Want your GitHub to look more professional?”
**Core:** Pin 3–6 strong projects, write useful READMEs, and make commit/project history understandable.
**CTA:** “Use these tips before sending your portfolio.”

## Production specs
- 9:16 vertical, 1080×1920
- 20–60 seconds each
- Captions burned in
- Strong first 1–2 seconds
- One idea per clip
- Light music under narration, if used
