# Mini Course — Python & Developer Skills Starter

## Lesson 1 — Python Foundations
Learn variables, data types, input/output, conditions, and the basic mental model for writing Python programs. Finish with a small interactive exercise.

## Lesson 2 — Build Your First Python Project
Apply Python fundamentals to a practical expense tracker. Learn how lists, loops, functions, and calculations work together in a small application.

## Lesson 3 — Git & GitHub Workflow
Understand repositories, commits, branches, remotes, push/pull, and the basic workflow used to manage code and collaborate.

## Lesson 4 — APIs & Real-World Software
Learn what APIs do, how requests and responses work, and how applications exchange data. Finish with a simple API request demonstration.

## Lesson 5 — Turn Projects Into a Portfolio
Learn how to write a useful README, organize projects, choose strong portfolio examples, and present work clearly to recruiters or clients.

## Course completion project
Build one small Python project, publish it to GitHub, write the README, and record a 60-second walkthrough explaining the problem, solution, and next improvement.
