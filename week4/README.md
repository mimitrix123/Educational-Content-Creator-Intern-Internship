# Major Project — Week 4: Educational Content Brand Launch

## Brand
**CodeSprint Academy** — *Learn. Build. Get Job-Ready.*

## Project goal
Launch a practical educational content brand across YouTube and short-form platforms, package the content into a mini-course, create a simple landing page, and document first-week analytics.

## Deliverables
- YouTube launch plan for 3 educational videos
- SEO metadata, thumbnail concepts, and end-screen plan
- 5 short-form clips
- 5-lesson mini-course outline
- Simple responsive landing page in `landing_page/index.html`
- Professional portfolio and launch checklist
- First-week analytics dashboard/template

## Launch video slate
1. **Python Expense Tracker in 8 Minutes** — beginner portfolio project
2. **Git & GitHub in 5 Minutes** — essential developer workflow
3. **What Is an API?** — beginner-friendly industry concept

## Short-form slate
