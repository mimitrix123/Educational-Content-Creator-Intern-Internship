# Week 3 — Editing & Production Plan

## Long-form video
- Canvas: 1920×1080, 16:9
- Record clean talking-head footage separately from screen capture.
- Capture coding at readable scale; avoid tiny editor text.
- Use jump cuts to remove pauses and repetitive typing.
- Add captions throughout.
- Highlight important code with zooms or callout boxes.
- Use low-volume background music only when it does not compete with narration.
- Normalize voice audio and check for clipping.
- Export as H.264 MP4 at 1080p.

## Shorts/Reels
- Canvas: 1080×1920, 9:16
- Keep the first 1–2 seconds visually strong.
- Add large burned-in captions.
- Reframe screen recordings so code remains readable.
- Use quick cuts and on-screen keywords.
- End with a simple CTA to watch the full tutorial or build the project.
- Export each clip separately for platform upload.

## Quality-control checklist
- [ ] No dead air or accidental pauses
- [ ] Voice is clear and music is below narration
- [ ] Code is readable on mobile
- [ ] Captions match narration
- [ ] No private tokens, passwords, or personal information visible
- [ ] Thumbnail text is legible at small size
- [ ] Titles accurately describe the content
- [ ] Description contains a clear value proposition
- [ ] Final exports play correctly before publishing
