# Week 3 — Short-Form Scripts

## Short 1 — Build a Python Expense Tracker in 60 Seconds

**Script:**
> Here's a tiny Python project you can build today. First, create an empty `expenses` list. Ask the user for an amount, convert it to a number, and append it to the list. Then calculate the total. Add a loop and users can enter multiple expenses. That's already a portfolio project. Now add categories or CSV export and make it yours.

**Format:** 9:16 vertical, captions, quick code zooms, 45–60 seconds.

## Short 2 — 3 Python Mistakes Beginners Make

**Script:**
> Three Python mistakes beginners make. Number one: forgetting that `input()` returns text, so convert numeric input when needed. Number two: unclear variable names — use names like `total_expenses` instead of `x`. Number three: writing code without testing small pieces. Run early, test often, and fix one problem at a time.

**Format:** 9:16 vertical, numbered on-screen callouts, 30–45 seconds.

## Short 3 — Python Expense Tracker Explained in 60 Seconds

**Script:**
> Don't just copy this Python expense tracker — understand it. The list stores expense amounts. `input()` gets data from the user. Numeric conversion lets Python calculate with that data. `append()` adds a new expense, and `sum()` gives the total. Once you understand those pieces, you can turn the same pattern into a budget tracker, sales calculator, or savings tool.

**Format:** 9:16 vertical, code highlights, 45–60 seconds.
